## 1. 需求概述

在 `https://longer8888.tech/asr-demo-multi/` 云端 ASR Demo 页面上，新增**声纹管理**功能，支持：

- ✅ 通过 **音频文件上传** 注册声纹
- ✅ 通过 **现场麦克风录音** 注册声纹
- ✅ **查询/列出** 当前所有已注册声纹
- ✅ **删除** 指定声纹
- ✅ 上传的临时音频文件注册后**立即自动删除**，服务启动时清理超过 1 小时的残留文件

## 4. 后端设计

### 4.1 配置项（server-cloud/config.ts）

复用现有 ASR 的 API Key（同一个 AppID 同时用于 ASR 和声纹），新增以下配置：

```typescript
// server-cloud/config.ts 新增
uploadsDir: string;        // 临时音频目录，默认 'uploads'
voiceprintBaseUrl: string; // 声纹 API 地址，默认 'https://openspeech.bytedance.com/api/proxy/invoke'
```

公网 AudioUrl 通过请求上下文自动构造（从 `Host` header + `X-Forwarded-Proto` + path 推断），无需硬编码。

### 4.2 目录初始化

服务启动时：
1. 创建 `uploads/` 目录（如不存在）
2. 扫描 `uploads/` 目录，删除所有**最后修改时间超过 1 小时**的文件（防止异常退出导致残留）
3. 记录清理日志

### 4.3 API 接口详细设计

#### 4.3.1 上传音频 `POST /api/voiceprint/upload`

| 项目 | 说明 |
|------|------|
| **方法** | POST |
| **Content-Type** | 不限制（直接发送二进制 body） |
| **请求头** | `X-File-Ext`: 文件扩展名，如 `.wav`, `.mp3`, `.webm`, `.m4a` |
| **请求体** | 原始二进制音频数据 |
| **大小限制** | ≤ 10 MB |
| **成功响应** | `{ "success": true, "url": "/uploads/vp_{uuid}.wav" }` |
| **失败响应** | `{ "success": false, "message": "错误原因" }` |

**处理流程**：
1. 校验 `X-File-Ext` 是否在允许列表中（`.wav`, `.mp3`, `.m4a`, `.webm`, `.ogg`）
2. 生成唯一文件名：`vp_{短uuid}_{时间戳}{ext}`
3. 将请求 body 流式写入 `uploads/` 目录
4. 返回可访问的公网路径

> **设计决策**：不使用 `multipart/form-data`，避免引入第三方解析库（如 `formidable`、`multer`），保持项目零额外依赖。前端直接 POST 二进制即可。

#### 4.3.2 注册声纹 `POST /api/voiceprint/register`

| 项目 | 说明 |
|------|------|
| **方法** | POST |
| **Content-Type** | `application/json` |
| **请求体** | `{ "speakerName": "张三", "audioUrl": "/uploads/vp_xxx.wav" }` |
| **成功响应** | `{ "success": true, "speakId": "xxxx", "message": "注册成功" }` |
| **失败响应** | `{ "success": false, "message": "错误原因" }` |

**处理流程**：
1. 校验 `speakerName`（非空，长度限制 2-64 字符）
2. 校验 `audioUrl`（必须是 `/uploads/` 开头的路径，防止路径遍历）
3. 构造完整公网 URL：`{protocol}://{host}{basePath}{audioUrl}`
4. 调用字节 openspeech `UpdateVoiceprint` API（Action=UPDATE, UpdateAction=0/CREATE）
5. **无论成功或失败，立即删除 `audioUrl` 对应的临时文件**
6. 返回结果（成功时包含 speakId）

#### 4.3.3 查询声纹列表 `GET /api/voiceprint/list`

| 项目 | 说明 |
|------|------|
| **方法** | GET |
| **成功响应** | `{ "success": true, "items": [{ "speakId": "...", "speakerName": "...", "createTime": "..." }] }` |

**处理流程**：
1. 调用字节 openspeech `ListVoiceprint` API
2. 映射字段为前端友好的格式
3. 返回列表（按注册时间倒序排列）

#### 4.3.4 删除声纹 `POST /api/voiceprint/delete`

| 项目 | 说明 |
|------|------|
| **方法** | POST |
| **Content-Type** | `application/json` |
| **请求体** | `{ "speakId": "xxxx" }` |
| **成功响应** | `{ "success": true, "message": "删除成功" }` |

**处理流程**：
1. 调用字节 openspeech `UpdateVoiceprint` API（UpdateAction=2/DELETE）
2. 返回结果

#### 4.3.5 临时音频静态服务 `GET /uploads/*`

与现有 `/recordings/*` 机制一致：
- 限制只能访问 `.wav/.mp3/.m4a/.webm/.ogg` 文件
- 路径遍历防护（`..` 过滤，必须在 uploads 目录内）
- 正确设置 `Content-Type` 响应头
- 字节服务需要公网可访问（现有 Nginx 配置已支持）

### 5.3 现场录音技术方案（直接输出 16kHz WAV）

**不使用 `MediaRecorder`**（因为 MediaRecorder 默认输出 WebM/Opus 格式，需要额外转码），而是直接复用现有项目的 PCM 采集方案：

1. **采集流程**（独立于 ASR 主流程）：
   - 点击「开始录音」→ 请求麦克风权限（`navigator.mediaDevices.getUserMedia`，单声道、开启回声消除/降噪/AGC）
   - 创建独立的 `AudioContext`（不影响主 ASR）
   - 通过 `ScriptProcessorNode` 采集 PCM 数据
   - 复用现有 `resampleTo16k()` 函数重采样到 16kHz
   - 复用现有 `floatTo16BitPCM()` 转为 16-bit PCM
   - 实时计算音量 RMS，驱动音量条动画
   - 计时器显示录制时长

2. **停止录音**：
   - 关闭麦克风流和 AudioContext
   - 将所有 PCM chunks 拼接为完整的 Int16Array
   - **构造标准 WAV 文件头**（44 字节）：
     ```
     - ChunkID: "RIFF"
     - ChunkSize: 36 + dataSize
     - Format: "WAVE"
     - Subchunk1ID: "fmt "
     - Subchunk1Size: 16 (PCM)
     - AudioFormat: 1 (PCM)
     - NumChannels: 1 (单声道)
     - SampleRate: 16000
     - ByteRate: 32000 (16000 * 1 * 2)
     - BlockAlign: 2 (1 * 2)
     - BitsPerSample: 16
     - Subchunk2ID: "data"
     - Subchunk2Size: dataSize
     ```
   - 合并 WAV 头 + PCM 数据，生成 Blob（MIME: `audio/wav`）
   - 创建 `<audio>` 元素预览播放
   - 显示「重录」按钮

3. **与 ASR 互斥**：
   - 如果当前 ASR 正在录音（`currentState === 'recording'`），提示「请先停止 ASR 识别后再进行声纹录音」
   - 声纹录音期间，禁用主页面的麦克风按钮

### 5.4 文件上传方案

1. 用户选择文件或拖拽文件后，读取为 `ArrayBuffer`
2. 根据文件扩展名设置 `X-File-Ext` header
3. 使用 `fetch()` 直接 POST 二进制到 `/api/voiceprint/upload`
4. 上传成功后，保存返回的 `audioUrl`
5. 创建音频预览播放器

### 5.5 注册流程

1. 用户填写「说话人名称」并准备好音频（上传或录音）后，「注册声纹」按钮变为可用
2. 如果是现场录音模式但尚未录音或未确认，提示先完成录音
3. 如果是文件上传模式但未上传文件，提示先选择文件
4. 点击「注册」后：
   - 按钮变为 loading 状态，防止重复提交
   - 状态行显示「注册中...」
   - 调用 `POST /api/voiceprint/register`
   - 成功：状态行显示「✅ 注册成功，SpeakId: xxx」，刷新声纹列表，清空表单/音频
   - 失败：状态行显示「❌ 注册失败：{错误消息}」，保留音频可重试

### 5.6 删除流程

1. 点击列表中的「删除」按钮
2. 弹出浏览器 `confirm()` 二次确认：「确定要删除说话人「{name}」的声纹吗？此操作不可恢复。」
3. 确认后调用 `/api/voiceprint/delete`
4. 成功后刷新列表
5. 失败显示错误提示

### 5.7 前端校验规则

| 校验项 | 规则 | 提示 |
|--------|------|------|
| 说话人名称 | 非空，长度 2-32 字符 | 「请输入说话人名称（2-32个字符）」 |
| 文件格式 | `.wav/.mp3/.m4a/.webm/.ogg` | 「请选择支持的音频格式」 |
| 文件大小 | ≤ 10 MB | 「文件过大，请选择小于 10MB 的音频」 |
| 录音最短时长 | ≥ 1.5 秒（推荐 ≥ 3 秒） | 「录音过短，请至少录制 3 秒」 |

## 6. 文件清理策略

| 时机 | 清理动作 |
|------|---------|
| 注册成功/失败响应前 | 立即 `unlinkSync()` 删除本次上传的临时音频文件 |
| 服务进程启动时 | 遍历 `uploads/` 目录，`fs.statSync()` 获取 `mtime`，删除 `Date.now() - mtime > 3600000`（1小时）的文件，并打印清理日志 |

## 8. 关键决策记录

| 决策 | 理由 |
|------|------|
| **直接 POST 二进制，不用 multipart** | 不引入 `multer`/`formidable` 等第三方依赖，保持项目简洁；实现简单 |
| **现场录音直接输出 16kHz 单声道 WAV** | WAV 是声纹模型最佳输入格式（无损、参数标准），避免服务端转码开销；复用项目已有 PCM 采集和重采样代码 |
| **临时文件注册后立即删除** | 避免磁盘堆积，减少敏感语音数据在服务器上的留存时间 |
| **启动时清理 >1 小时残留** | 防止进程崩溃/异常退出导致临时文件泄漏，1 小时是合理的兜底窗口 |
| **Modal 弹窗而非独立页面** | 与现有的「参会名单」「会议导入」交互保持一致，减少 UI 复杂度 |
| **声纹录音与 ASR 互斥** | 浏览器同一时间只能有一个 `getUserMedia` 音频采集上下文，避免冲突 |
